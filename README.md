# TeachLink – AI Powered Tutor & Student Matching Platform

## 📖 Project Overview

TeachLink is a Final Year Project (FYP) developed to connect students with suitable tutors using Artificial Intelligence. The platform helps students find tutors based on their learning needs while allowing tutors to manage their profiles, schedules, students, and sessions efficiently.

---

## 🚀 Features

### 👨‍🎓 Student

- Complete Profile
- Find Tutors
- AI Tutor Recommendation
- Request Tutors

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/kiran-mankani/TeachLink.git
```

## Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```
